# Standing instructions for Claude in this repository

## Credits and paid services: ask first, always

**Never use credits, paid quota or any metered service on the user's behalf without the user's explicit permission first, on any site or tool.**

This covers, for example: ElevenLabs, Higgsfield, Everygen, any image, video, speech or other generation service, paid APIs, and any connector whose calls cost credits.

Before each use:
1. Say what you want to generate and why.
2. Give the estimated cost (use an estimate-only option if the tool has one).
3. Wait for a clear "yes". Permission for one use does not cover the next.

If the user says no, do the work with free local tools (for example a silent animation with subtitles).

*(Rule added by the course author, Prof. Basem M. ElHalawany, after narration credits were used on ElevenLabs without asking first.)*
