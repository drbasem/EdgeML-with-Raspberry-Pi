2. What is Edge AI?
  • Cloud AI: my data travels to a data centre, the model computes, the answer travels back.
  • Edge AI: the AI algorithm runs locally, on the device next to the data: a camera, robot, factory sensor, phone or a Raspberry Pi.
  • The "edge" = the edge of the network, where data is born.
  • Result: systems that are more responsive, private and efficient.
3. Training and inference
  • A model is a program whose behaviour is learned from examples instead of written by hand.
StageWhat happensWhere in this course
Trainingshow the model many examples; it adjusts its internal numbers until answers are good. Heavy: lots of data, fast processor.laptop or cloud (Colab, Edge Impulse)
Inferencegive the trained model new data (photo, sound, question); it answers. Light: milliseconds to seconds.on the Raspberry Pi
Typical project: train (or download) once, shrink the model to fit a small device, then run inference on the Pi again and again.

Why the edge? Two families of AI
4. Five reasons Edge AI matters
AdvantageWhat it means in practice
Low latencyanswer in milliseconds, no network round trip: a robot reacts now
Privacysensitive images / audio stay on the device
Network independencekeeps working with no Internet: tunnel, field, ship, factory
Less bandwidthsend only the result (a few bytes), not a video stream
Energy efficiencysmall optimised models on small hardware use little power
The price of the edge: small processor, limited memory, limited power budget -> models must be small and optimised (e.g. lower numerical precision). Fitting a model to the hardware is a theme of the whole course.
5. Two families of AI
Fixed-function (reactive)
  • analyses a specific input using predetermined patterns / rules
  • responds only to particular triggers
  • consistent, predictable output
  • excels at structured tasks: classify, detect, recognise
  • works within its boundaries
Generative (proactive)
  • creates new content: text, descriptions, solutions
  • understands context
  • keeps a dialogue going
  • adapts to situations beyond its training
Fixed-functionGenerative
Core focusdata analysis, assessment, automationcontent creation, anticipation, dialogue
Examplesfraud detection, spam filters, image recognition, counting objectschat assistants, image generators, predictive maintenance, smart assistants
Typical usebanking, medical diagnostics, securitycontent, customer support, design, automation
In this coursePhase 2: classification, detection, countingPhase 3: language models, vision-language, agents
Rule of thumb: fixed-function = efficient, predictable, low resources, well-defined task. Generative = creative, personalised, anticipatory. Both gain from the edge: lower latency, privacy, reliability offline, efficient resources.

The Raspberry Pi
7. A computer on a single board
  • Single-board computer (SBC): a complete computer on one circuit board: processor, memory, network + video connectors, pins for electronics.
  • Its main chip is a system on a chip (SoC): CPU cores, graphics and controllers in one package.
  • No built-in disk. The OS and my files live on a microSD card. Swap the card = swap the computer's whole "personality".
8. Why the Pi suits Edge AI
FeatureWhat it gives me
Computational powermulti-core ARM CPUs, up to 8 GB RAM on newer models
GPIO, 40 pinseach pin reads a signal (button, sensor) or drives one (LED, relay)
ConnectivityWi-Fi, Bluetooth, Gigabit Ethernet, USB
I2C, SPI, UARTserial buses for sensors, displays, other chips
Soft real-timecontrol / signal tasks that tolerate small timing variation
Power efficiencysuits battery-powered and always-on designs
Full Linux + communitystandard tools, huge community, low cost
9. What engineers build with a Pi
  • Embedded systems: prototyping devices
  • IoT: sensors using MQTT, CoAP, HTTP(S)
  • Control systems: feedback loops, PID, actuators
  • Vision + AI: OpenCV, TensorFlow Lite
  • Data acquisition: sensor logging, real-time analysis
  • Robotics: controllers, motion planning
  • Signal processing: real-time filtering, DSP
  • Network security: VPNs, firewalls, test labs

Operating system basics
17. What is an operating system?
  • Software that manages the hardware and the software resources and gives programs standard services. It sits between the hardware and my applications.
Your programs - Python scripts, Jupyter, AI models
Shell / desktop - where I type commands or click
Kernel + drivers - processes, memory, files, devices
Hardware - CPU, RAM, microSD, Wi-Fi, USB, camera, GPIO
It manages
  • processes: shares CPU time
  • memory: gives and frees RAM
  • files: files and folders
  • devices: via drivers
  • user interface
Made of
  • kernel: the core, controls hardware
  • shell: where I type commands
  • file system: how data is stored
  • drivers: talk to devices
18. Linux, Debian, Raspberry Pi OS
  • Linux: family of free, open-source operating systems around the Linux kernel. A distribution = kernel + tools + libraries + package manager.
  • Debian: one of the oldest, most widely used distributions.
  • Raspberry Pi OS (formerly Raspbian): Debian adapted for the Pi's ARM processors. Lightweight, versatile, open source, GPIO support, regular updates.
Versions and Python: releases follow Debian (e.g. Debian 12 "Bookworm"; newer ones exist). Imager offers the current one; the steps are the same. The Python version can differ, and some ML packages are slow to support the newest Python. Day 5 handles it with virtual environments. Record my OS and Python versions today.
19. Which image do I choose?
Choice in ImagerWhat it isMine?
Raspberry Pi OS (64-bit)full system with desktop; many AI libraries need 64-bitYES (Pi 4 and Pi 5)
Raspberry Pi OS Lite (64-bit)no desktop, saves RAM (for tiny boards like the Zero 2 W)not needed
32-bit versionsolder; fewer AI packagesavoid
64-bit? More memory addressable, full CPU instruction set. Check later with uname -m: aarch64 = 64-bit ARM, armv7l = 32-bit.

Just enough networking
20. How the laptop will find the Pi
IdeaExplanation
Routerconnects my devices (Wi-Fi or cable) to each other and to the Internet
IP addressa device's number on the network, e.g. 192.168.1.57 (four numbers 0-255). 192.168.x.x, 10.x.x.x, 172.16-31.x.x are private: they work only inside my network
DHCProuter service that gives each device an address automatically; it can change from day to day
Host namefriendly name I choose, e.g. raspi4
.local namedevices announce their names inside the network (mDNS), so raspi4.local works without knowing the IP. Only inside one network; some networks block it
Wi-Fi bands2.4 GHz: longer range, slower. 5 GHz: faster, shorter range. Pi 4 and Pi 5 use both; Pi Zero 2 W only 2.4 GHz
21. Networks that make life harder
  • Guest networks and some office / university networks isolate devices: the laptop cannot see the Pi.
  • Enterprise networks (WPA2-Enterprise) need a user name too: Imager's simple Wi-Fi form cannot do that.
  • Login-page (portal) networks do not work for a Pi without a screen.
  • In all cases: use a phone hotspot or an Ethernet cable to a home router for the first connection.

Prepare the microSD card
22. The idea
  • At power-up the built-in firmware looks for an OS on the microSD card. "Installing the OS" = writing an image (a complete ready-to-run copy of the system) onto the card.
  • Tool: Raspberry Pi Imager (free; Windows, macOS, Linux). It can also store my settings (host name, user, password, Wi-Fi, SSH) so the Pi needs no monitor or keyboard = headless.
23. Install Imager; before I start
  • download Imager from raspberrypi.com/software, run the installer, open it
  • microSD card (32 GB+) in a reader
  • Wi-Fi name + password ready
  • card backed up: Imager erases it
  • other USB drives unplugged (so I cannot pick them by mistake)
24. Steps on Windows
  1. Insert the card. If Windows says "format the disk?" -> Cancel.
  2. Device = Raspberry Pi 4 (Pi 5: Raspberry Pi 5)
  3. OS = Raspberry Pi OS (64-bit)
  4. Storage = my card (check size + drive letter!)
  5. Next -> open the settings (gear icon / "customise")
  6. Write -> verify -> "Write successful" -> remove card
Imager with device, OS and storage chosen (example on a Mac, older release)
Careful! Imager erases whatever drive I choose. Wrong drive = lost data.

First boot
27. Steps
  1. Card into the slot on the underside (contacts toward the board).
  2. Optional monitor (micro-HDMI port nearest the USB-C) and keyboard first.
  3. Power last. Pi 4: no power button, plug in = on. Pi 5: 27 W supply; it has a power button.
  4. Wait a few minutes; it may restart once. Do not unplug!
28. What happens during first boot
Step 4 happens only the first time: the Pi grows the file system to fill my card and applies the settings I typed in Imager.
29. Reading the LEDs

First SSH login
30. What is SSH?
  • SSH (Secure Shell): the Pi's command line in a window on my laptop. An SSH server on the Pi (port 22) and an SSH client on the laptop; everything travels encrypted. No monitor, keyboard or mouse needed on the Pi.
  • Both machines must be on the same network.
31. Steps on Windows
  1. Start -> PowerShell. Test: ssh -V. (Missing? Settings -> Apps -> Optional features -> OpenSSH Client.)
  2. Connect (below), by name or IP.
  3. First time: type the whole word yes to trust this Pi.
  4. Password: nothing shows as I type: normal!
  5. Prompt piuser@raspi4:~ $ = I am inside the Pi.
a first login (example on a Mac)
PS C:\> ssh piuser@raspi4.local  (or ssh piuser@192.168.1.57)
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes
piuser@raspi4.local's password: (invisible)
piuser@raspi4:~ $ _
Mac / Linux: Terminal, same command. PuTTY is an older graphical option on Windows.
32. Reading the prompt
piuser @ raspi4 : ~ $user @ host-name of the machine I am on (the Pi) : current folder (~ = home) and $ = ready for a command. exit leaves.

34. Updating the system
  • Software comes in packages handled by apt. sudo = "run as administrator" (asks my password).
sudo apt-get update  # refresh the package list
sudo apt upgrade  # install newer versions; answer Y when asked
Needs Internet; may take minutes the first time; do it regularly; sudo reboot after a kernel update.
35. Shut down safely, every time
Never just pull the plug. The Pi may still be writing to the card: data loss or a corrupted card.
sudo shutdown -h now  (halt)    sudo reboot  (restart)
Wait until the green LED stops flashing and stays dark, then unplug.
  • Start a halted Pi 4 again: unplug + replug. Pi 5: press the power button.
  • Files between laptop and Pi (Day 2): USB drive, scp, or SFTP (FileZilla / WinSCP).
