2. What is Edge AI?
  • Cloud AI: my data travels to a data centre and the answer travels back.
  • Edge AI = the model runs ON the device next to the data (camera, robot, sensor box, a Pi).
  • Book: PDF pp. 20-21 and 25-27 (printed page + 1).

7. The idea
  • The Pi has no hard disk. It boots from the microSD.
  • "Installing the OS" = writing an image onto the card with Raspberry Pi Imager.
  • I also bake in my settings (name, user, Wi-Fi, SSH): no monitor or keyboard needed = headless.
8. Which operating system?
Choice in ImagerWhat it isMine?
Raspberry Pi OS (64-bit)full system with desktop; 64-bit needed by AI librariesYES
Raspberry Pi OS Lite (64-bit)no desktop, uses less RAM (book uses it on the Pi Zero)not today
32-bit versionsolder, less compatibleavoid
The book says "Debian Bookworm". A newer Imager may offer a newer Debian. Steps are the same, but the Python version may differ and TFLite is picky - I record it today and check on Day 4-5.
9. Before I start
  • Raspberry Pi Imager installed (raspberrypi.com/software)
  • Wi-Fi name + password ready
  • card backed up - Imager erases it
  • other USB drives unplugged (so I cannot pick them by mistake)

10. Steps on Windows
  1. Open Imager. If Windows says "format the disk?" -> Cancel.
  2. Device = Raspberry Pi 4
  3. OS = Raspberry Pi OS (64-bit)
  4. Storage = my card (check size + drive letter!)
  5. Next -> edit settings (gear icon / "customise")
  6. Write -> verify -> "Write successful" -> remove card

First boot & first login
12. First boot (15 min)
  1. Card into the slot on the underside (contacts toward the board).
  2. Optional monitor / keyboard first.
  3. Power last (USB-C, 5 V / 3 A). The Pi 4 has no power button.
  4. Wait a few minutes; it may restart once. Do not unplug!
first boot: resizes the file system, applies my settings, starts SSH (1-3 min)
13. First SSH login from Windows (20 min)
  • SSH = Secure SHell: the Pi's command line in a window on my laptop, encrypted. Same Wi-Fi needed.
  1. Start -> PowerShell. Test: ssh -V
  2. Connect (below). First time: type yes.
  3. Password: nothing shows as I type - normal!
  4. Prompt piuser@raspi4:~ $ = I am inside the Pi.
book (PDF p.38): first login on a Mac
PS C:\> ssh piuser@raspi4.local
Are you sure you want to continue connecting (yes/no)? yes
password: (invisible)
piuser@raspi4:~ $ _
Book PDF pp. 38-39. Slides: Class 3, slide 7 (on Windows use cmd or PowerShell).

Commands & troubleshooting
14. My first five commands
CommandWhat it does / what I should see
hostname -Ithe Pi's IP address - write it down
uname -mwant aarch64 (= 64-bit); armv7l means 32-bit

ALWAYS shut down properly:  sudo shutdown -h now
Wait until the green LED is dark, then unplug. Pulling the plug can corrupt the card.
