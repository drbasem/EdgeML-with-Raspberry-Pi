My 46-day roadmap
Pi 4 (4 GB)  |  2 Pis + 2 laptops  |  2 hours a day  |  ~9 weeks

Two Pis, two laptops: do every day twice

Pass 1 - learn

on Pi A, ~2 hours: tutorial + animation + lab + notes

Pass 2 - consolidate

on Pi B, from my notes only. Faster. Finds the hidden mistakes
  • different host names: raspi-office / raspi-home, same user
  • code + notes in GitHub, then git pull everywhere
  • Phase 1 needs no Pi (Colab) - good for travelling

Get ready (by day)

  • 1 Pi 4, microSD 32 GB+, 5 V / 3 A supply, card reader
  • 4 Pi camera (CSI) or USB webcam
  • 6 Google account (Colab)   13 Edge Impulse account
  • 35 USB mic + speaker
  • 36 breadboard, wires, LEDs + resistors, button, DHT + BMP280 sensors
Honest limits: 4 GB = small language models only, slower than the book's Pi 5. Check Python vs TFLite on day 4-5. Day splits are estimates.
