How the course works
3. The rules of the game
  • One day = about 2 hours. Every day has a full tutorial (complete in itself: no book or website needed), a narrated animation where it helps, hands-on steps, a quiz, and notebook notes with space for my own comments.
  • Pi 4 and Pi 5: every day works on both boards. Where they differ (speed, memory, power, camera cable, model sizes) the lesson says so.
  • Learn it twice: with two Pis, learn on one, then repeat on the other from my notes only. Different host names (raspi-lab, raspi-home), same user, code and notes in a shared online repository.
  • Phase 1 needs no Pi, only Google Colab: do it anywhere.
  • Day sizes are estimates; a long day simply continues the next day.
4. Notes on hardware and software
Pi 4 and Pi 5: the vision phases run well on both. A Pi 4 does not run language models well (only very small ones, slowly): do Phase 3 on a Pi 5 (8 GB recommended), or treat it as a guided demonstration.
Python: a newer Raspberry Pi OS may ship a newer Python than some ML packages support; days 4-5 include the check and the remedy.
Online services (Colab, Edge Impulse, model downloads) need Internet; use a phone hotspot if the network restricts them.
UNO Q is an optional extension.
5. Get ready (by day)
  • day 1  Raspberry Pi 4 or 5, microSD (32 GB or more), the matching USB-C power supply, card reader, Wi-Fi details
  • day 4  Pi camera module (check the camera cable: it differs between Pi 4 and Pi 5) or a USB webcam
  • day 6  Google account
  • day 13  Edge Impulse account (check the current free tier)
  • day 27  Internet on the Pi for model downloads; enough free space on the card
  • day 35  USB microphone and speaker
  • day 36  Breadboard, jumper wires, LEDs with resistors, push button, DHT temperature sensor, BMP280 pressure sensor (confirm the exact parts in the lessons before buying)
  • day 47+  Arduino UNO Q (optional)
