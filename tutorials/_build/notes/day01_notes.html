My 2 hours

A · Big picture: what is Edge AI?

Cloud AI: my data travels to a data centre and back. Edge AI = the model runs ON the device next to the data (camera, robot, sensor box, a Pi).

5 reasons it matters (book)

  • Low latency - answer in milliseconds, no round trip
  • Privacy - raw images / audio stay on the device
  • Network independence - works in a tunnel, field, factory
  • Less bandwidth - send a result, not a video stream
  • Energy efficiency - small optimised models, small power

C · Flash the microSD card (45 min)

The Pi has no hard disk. It boots the OS from the microSD. "Installing the OS" = writing an image onto the card with Raspberry Pi Imager. I bake in my settings too, so no monitor or keyboard is needed (headless).

Which OS?

Raspberry Pi OS (64-bit)
with desktop - my choice
Lite = no desktop (book uses it for the tiny Zero). 32-bit: avoid.

Before I start

  • Imager installed
  • Wi-Fi name + password
  • unplug USB drives!
  • card backed up

Steps on Windows

  1. 1Open Imager. If Windows says "format the disk?" -> Cancel
  2. 2Device = Raspberry Pi 4 (Pi 5: choose Pi 5)
  3. 3OS = Raspberry Pi OS (64-bit)
  4. 4Storage = my card (check size + drive letter!)
  5. 5Next -> edit settings (gear icon / "customise")
  6. 6Write -> verify -> "Write successful" -> remove card

D · First boot (15 min)

  1. 1Card into the slot on the underside (contacts toward the board)
  2. 2Optional monitor / keyboard first
  3. 3Power last (USB-C, 5 V / 3 A) - Pi 4 has no power button
  4. 4Wait a few minutes. It may restart once. Don't unplug!

E · First SSH login from Windows (20 min)

SSH = Secure SHell: the Pi's command line in a window on my laptop, encrypted. Same Wi-Fi network needed!

  1. 1Start -> PowerShell. Test ssh -V
  2. 2Connect (below). First time: type yes
  3. 3Password: nothing shows as I type - normal!
  4. 4Prompt piuser@raspi4:~ $ = I'm INSIDE the Pi

First 5 commands

ALWAYS shut down properly: sudo shutdown -h now
wait until the green LED is dark, then unplug. Pulling the plug can corrupt the card!
